## 2026-09-27：只改善展示，不简化规则

仍然是一根杖独立计时、每次释放下一张主动法术、末尾循环。符文占槽但不进入释放队列；弹丸命中前法杖继续计时，辅助法术直接生效。双杖互充、状态消耗与护盾导流保持不变。

- 施法队列显示原槽号、高亮下一发，并给刚释放的卡描边；符文独立显示在被动区。
- 法杖指向敌人，计时光环、杖口闪光、后坐反馈、弹丸尾迹及来源标记一起呈现发射。
- 每杖独立显示最近释放、当前飞行数量、最近命中伤害与附加效果，以及最后收到的联动来源。
- 「看到下一次释放」推进至任一己方杖下一次施法并暂停，不改变时间步或施法规则；同一时间步双方事件照常结算。
- 「最近释放」「飞行途中」「最近命中」是各自的状态摘要，不代表同一发弹丸：新一发可以释放，上一发仍在飞。
- 手机端两个监视面板上下排列；长队列自动将下一发移到可见区域。

推荐：开始实验 → 看到下一次释放 → 看“刚释放”与“下一发” → 前进0.25秒观察飞行和命中。点「继续」恢复全自动战斗。

验证：`node prototype/link-engine.test.cjs`（24组）；`output/playwright/readability-smoke.js` 是通过 Playwright CLI 执行的界面测试。数值尚未做平衡。

## 以下是单杖旧版说明（仅对应 legacy.html）

# 余烬工坊 · 自动法杖实验室 v0.3

零构建、零运行依赖的浏览器机制原型。**从左到右自动施法，只有一个施法间隔；末尾直接循环。** 无魔力、无整轮重充能，战斗中不需要操作。

## 打开

直接用Edge/Chrome打开本目录 `index.html`，或在项目根目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory prototype
```

访问 `http://127.0.0.1:8765`。已有旧页面时用Ctrl+F5刷新。

## 先试「加速充能」

疾行符 → 回响弹 → 充能符 → 重矛。观察自身**法杖**加速和计时跳进；角色状态与法杖效果分开显示。充能只减少现有施法条的剩余计时，不是魔力。

## 其他测试配方

1. **灼烧引爆**：余烬 → 余烬 → 引爆。观察敌方灼烧叠层、每秒衰减，以及被引爆清空。
2. **毒盾消耗**：毒刺 → 护盾 → 冰针。对战壁垒，观察中毒无视护盾扣生命。
3. **感电连击**：电弧 → 火花 → 火花。后续命中每次消耗一层感电并增加6直伤。
4. **净化反击**：净化 → 护盾 → 重矛。换成蚀火术士，观察自身状态被清除。

普通法术一槽一发。默认隐藏触发/双重/修饰模块；选择“进阶·触发爆发”会自动显示。施法追踪和组合树默认折叠。默认0.5倍，暂停后可每次前进0.25秒。

## 关键词（自定义规则，不是大巴扎原版规则）

| 目标 | 关键词 | 效果 |
|---|---|---|
| 法杖 | 加速 | 计时速度×1.5；持续时间由卡牌指定，重施刷新、不叠强度 |
| 法杖 | 减速 | 计时速度×0.7；重施刷新、不叠强度，与加速相乘 |
| 法杖 | 充能 | 立即扣减当前剩余计时，最低0，溢出丢弃，不递归施法 |
| 角色 | 灼烧 | 每秒按层数伤害，先扣盾，再减1层；上限30 |
| 角色 | 中毒 | 每秒按层数直接扣生命，无视盾与减伤，不自然衰减；上限30 |
| 角色 | 感电 | 后续每次弹丸命中消耗1层，直伤+6；上限6；跳伤不触发 |
| 角色 | 护盾 | 优先吸收直伤与灼烧，不阻止中毒或状态附着；上限55 |

**引爆弹与净化是卡牌，不是关键词。** 引爆弹消耗灼烧造成爆发；净化移除角色负面状态，并清除自身法杖减速。卡牌决定时机、目标和数量，关键词提供可复用规则。

首次附着1秒后才跳伤；叠层不重置跳伤时间。护盾不阻止状态附着。固定步顺序：施法 → 弹丸 → 持续伤害 → 判胜负。净化同跳伤步时先净化。详情见 `../docs/自动法杖_v0.3_关键词目标与卡牌分离_2026-09-26.md`。

## 实现范围

- 19模块（14基础+5进阶）、8槽、3法杖、4对手、7预设。
- 3种法杖只有一个计时参数，基础直伤倍率提供快慢区别。
- 真实飞行时间、简化一维碰撞、障碍、穿透、进阶载荷、护盾、治疗、七关键词。
- 状态层数与下一跳提示、关键词规则、事件日志、持续伤害统计。
- 固定1/60秒模拟；相同配置得到相同本地结果；45秒超时平局。
- 桌面与移动布局，暂停/步进/0.5/1/2/4倍速、重置及同配置重跑。

## 明确限制

不是Noita物理复刻；固定站位、单目标、无自伤、无弹丸互相碰撞。爆裂弹没有范围伤害。障碍载荷从碰撞点前方生成，可越过障碍。辅助始终作用于施法者。

**v0.3纠正关键词分类并新增法杖节奏效果；v0.1基线不再适用。尚未做竞技平衡或真实玩家测试。** 取消魔力后进阶多重/强化可能过强；速射状态和毒盾也可能强于普通直伤。默认隐藏进阶不等于解决平衡。没有商店、金币、成长、存档、音效、联机或完整二维物理。

双重充能可导致逐模拟步施法：已防止同帧无限递归，但未解决高频循环平衡。充能符占用一次施法，单杖收益可能不足；目前是机制验证卡。
