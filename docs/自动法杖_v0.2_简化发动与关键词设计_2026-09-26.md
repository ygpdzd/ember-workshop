# 自动法杖 v0.2：简化发动与关键词设计

日期：2026-09-26  
状态：已在 `prototype/` 实现；机制可测试，尚未完成数值平衡。  
定位：借用“自动战斗 + 战前构筑 + 状态联动”的方向，以下均为本原型自定义规则，不是大巴扎或 Noita 的原版规则说明。

## 1. 这次为什么删规则，而不是继续加提示

上一版需要同时理解：槽位、表达式分组、魔力、回魔、施法间隔、整轮重充能、飞行与载荷。即使每个环节都有反馈，观察者仍要把它们拼起来。

本版把基础规则压缩成一句话：

> 从左到右，每隔一段固定时间施放一个法术；最后一发之后直接循环。

### 删除或降级

- 删除魔力、费用、缺魔等待以及凝神回魔法术。
- 删除整轮重充能；第一次出手也等待同一个间隔，不再有独立的0.3秒起手。
- 普通法术一槽一发，不需要理解前缀语法。
- 触发、双重施放和修饰符保留为进阶模块，默认不出现在档案里。
- 施法追踪、程序树默认折叠；上方只显示法术顺序、下一发、一个进度条。
- 保留弹丸飞行、命中、障碍及进阶载体。下一发不等待上一发命中。
- 全自动要求不变：玩家只在开战前编排，不增加战斗中操作。

### 法杖差异

| 法杖 | 唯一施法间隔 | 基础直伤倍率 | 预期定位 |
|---|---:|---:|---|
| 铜枝 | 0.95秒 | 1.00 | 对照与入门 |
| 蜂鸣 | 0.65秒 | 0.65 | 高频状态施加、低单发直伤 |
| 沉星 | 1.30秒 | 1.45 | 单发直伤、对抗固定减伤 |

倍率不影响状态层数、状态伤害、感电增伤、引爆增伤、治疗及护盾。此划分使快慢法杖拥有不同方向，但也使速射更适合状态/辅助，这是需要测量的风险，不是已证明的平衡。

## 2. 六个关键词：四种状态 + 两种操作

| 关键词 | 精确定义 | 构筑目的 | 反制或代价 |
|---|---|---|---|
| 灼烧 | 每秒按当前层数造成伤害，先扣护盾，然后减少1层；无视固定减伤，上限30层 | 较快的持续压力、引爆燃料 | 自然衰减；净化；护盾吸收 |
| 中毒 | 每秒按当前层数扣生命；无视护盾和固定减伤，不自然衰减，上限30层 | 长局成长，克制堆盾 | 起效较慢；净化；快速直伤击杀施毒者 |
| 寒冷 | 施法计时速度降低30%，持续2秒；重施刷新，不叠减速比例 | 拉长对手出手间隔，争取持续伤害时间 | 占用输出槽；净化；不阻止已有弹丸和持续伤害 |
| 感电 | 后续每次弹丸命中消耗1层，本次直伤额外+6；上限6层，无自然倒计时 | 铺垫后靠多次命中兑现 | 不会自己造成伤害；净化；护盾/固定减伤仍有效 |
| 引爆 | 命中消耗全部灼烧，每层追加2点直伤；与弹丸基础直伤一起受护盾和固定减伤影响 | 将未来伤害提前，创造顺序选择 | 没灼烧只有基础伤害；消耗后不再继续灼烧 |
| 净化 | 自身灼烧、中毒各减3层；清除所有寒冷和感电；回复4生命 | 给负面状态一个可构筑的反制 | 占用一次出手机会；不是免疫，持续叠层可压过有限净化 |

### 为什么不把灼烧和中毒做成换颜色的同一效果

- 灼烧偏短期压力，有衰减；中毒偏长局，无衰减且穿盾。
- 灼烧拥有“继续跳伤”与“立即引爆”的选择；毒需要防御和寒冷帮助拖时间。
- 感电不跳伤，必须被后续命中兑现，奖励攻击次数而非等待。
- 净化同时覆盖多个状态，先用一个反制模块控制新增知识量。

### 引爆不是无条件增伤

灼烧N层、不再叠加或净化且有足够时间时，最多自然造成 `N×(N+1)/2` 点伤害；引爆则立即兑现 `2N` 点追加直伤。比如7层灼烧未来理论总伤害28，引爆追加14。后者的价值是“现在击杀/避免对手净化”，不是凭空获得更多总伤害。实际收益仍受护盾、减伤、战斗结束和后续补火影响。

## 3. 法术与一键配方

新增：余烬弹（4直伤+4灼烧）、毒刺（2直伤+2毒）、电弧（6直伤+2感电）、引爆弹（8直伤+引爆）、净化。冰针改为5直伤+2秒寒冷。

保留：火花弹、护盾、修复、爆裂弹、重矛。重设爆裂弹/重矛为16/20基础直伤，因为取消魔力后不能继续依赖高费用平衡强弹丸。该调整只是起点，不代表所有基础弹丸已经各有优势。

| 配方 | 顺序 | 观察问题 |
|---|---|---|
| 灼烧引爆（默认） | 余烬 → 余烬 → 引爆 | 能否看懂先附着再消耗？把引爆移到最前面会怎样？ |
| 毒盾消耗 | 毒刺 → 护盾 → 冰针 | 毒能否穿过壁垒护盾？防御是否延长有效输出时间？ |
| 感电连击 | 电弧 → 火花 → 火花 | 后两次命中是否各消耗1感电并增加6伤害？ |
| 净化反击 | 净化 → 护盾 → 重矛 | 面对蚀火术士，移除状态能否补偿少打一发？ |
| 稳定速射 | 火花 → 火花 → 冰针 | 简单无结构基线；与哨卫是镜像对局 |
| 进阶·触发爆发 | 触发 → 双重 → 余烬 → 引爆 | 能否读懂一发载体带两种效果？本配方不作为平衡基准 |

新增敌人“蚀火术士”：余烬 → 毒刺 → 火花。只用旧的无状态敌人无法验证净化价值。

## 4. 结算边界（已落到代码和测试）

1. 单步固定1/60秒。步骤：双方计时与施法 → 已有弹丸移动/碰撞 → 双方持续伤害 → 胜负判断。
2. 同一模拟步双方结算完再判胜负，持续伤害也可造成平局。净化恰逢跳伤的同一步时先移除层数，再用剩余层数跳伤。
3. 灼烧/中毒首次施加后1秒才跳伤，之后每秒一次。已有层数时重新施加不推迟下一跳；完全清除后重新附着则重新计1秒。
4. 护盾只阻挡伤害，不阻止状态附着。场景障碍不携带状态，也不会触发目标的感电或引爆；穿透可绕过障碍。
5. 弹丸命中先消耗已有感电，再处理引爆和本次直伤，最后施加新状态。新电弧不能立刻吃自己刚加的感电；但可消耗旧感电再补新层数。
6. 持续伤害不触发感电、命中载荷或新一轮附着，避免事件递归。
7. 进阶强化只乘基础直伤，不乘状态层数与感电/引爆追加值。修复、护盾、净化即使由远程载荷执行，也作用于施法者。
8. 统计只计实际失去的生命，不计过量伤害；护盾吸收单独记录。持续伤害是总生命伤害的子集。
9. 所有状态在新对局重新初始化。暂停冻结计时，速度按钮只改变观察速度。

## 5. 视觉反馈

- 施法顺序卡只标法术名、关键词和“下一发”，没有费用。
- 双方血条下显示当前负面状态、层数/剩余时间；桌面还显示持续伤害下一跳倒计时。
- 角色旁使用对应颜色标出灼烧、中毒、感电；跳伤、感电消耗、引爆有独立浮字和日志。
- 关键词说明可点击展开；移动端不依赖悬浮才能查规则。
- 默认0.5倍；暂停后可前进0.25秒。详细发射编号仍在，但追踪默认折叠。

## 6. 验证与未解决风险

- 27组Node规则测试通过，覆盖144种预设/法杖/敌人/障碍组合的终止及数值范围。
- Edge桌面1440×1100、移动390×844验证：默认简化、状态徽章、步进、配方、进阶开关、配置锁定、清空/不完整组合校验、重开清状态、关键词说明与帮助。
- 这些测试证明“机制符合定义”，不能证明“流派平衡或玩家能理解”。

### 当前已知风险

- **取消魔力后，双重/强化的机会成本不足。** 仍保留作为进阶试验，但默认隐藏，不假称与普通法术同等强度。后续可测试槽位权重/施法组预算；不要立即把魔力和第二个冷却加回来。
- **中毒可能成为长局最优解。** 层数上限和净化只是安全边界，不能代替对局矩阵与玩家测试。
- **速射可能在状态和辅助构筑中明显占优。** 快慢法杖倍率只作用于基础直伤，需记录施毒量、护盾效率和生存时间后再调。
- **单发重矛可能比基础火花更好。** 弹速带来的启动劣势未必足以抵消单发伤害差；后续考虑让基础弹拥有更明确的状态联动定位。
- **同帧双重载荷按槽位顺序结算。** 余烬与引爆在相近位置生成时，左侧先结算可能立即引爆，是确定性原型规则，尚未验证公平性。
- **这里只简化发动，没有移植完整Noita物理。** 仍是固定站位、单目标、一维命中轴、无真实范围伤害。

### 下一轮验证问题

1. 新玩家能否在不展开说明的情况下，预测下一发和循环顺序？
2. 能否说出灼烧与中毒的两个差别，而不是只记住颜色？
3. 把默认引爆换位置后，能否解释结果差别？
4. 状态术士与壁垒能否使净化、毒、直伤形成不同的有效选择？
5. 简化后是否出现“只装一张最强法术”的明显支配策略？出现就先处理机会成本，不继续扩充关键词数量。
