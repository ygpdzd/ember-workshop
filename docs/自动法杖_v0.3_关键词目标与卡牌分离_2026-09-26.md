# 自动法杖 v0.3：按作用目标定义关键词

日期：2026-09-26。本文替代 v0.2 文档中的关键词分类；基础发动仍为「倒计时 → 下一槽 → 循环」。这是原创原型规则，不是对大巴扎或 Noita 原版机制的复述。

## 1. 先区分三个概念

- **关键词**：可供不同卡牌复用的标准机制，首先定义目标类型。例如「使自身法杖充能0.5秒」。关键词不一定是持续状态，充能就是即时效果。
- **卡牌**：指定触发时机、目标、关键词和数量，必要时使用条件或消耗规则。例如「引爆弹：命中时消耗敌方角色全部灼烧，每层增加2直伤」。
- **结构模块**：决定法术怎样组织，例如双重施放、命中载荷；不是角色状态或法杖计时关键词。

统一卡牌句式：**何时 → 对谁 → 施加/消耗什么 → 多少**。同一关键词应能由多张不同卡使用，避免一张卡就是一个专属关键词。

## 2. 本轮已实现的关键词

| 目标 | 关键词 | 标准规则 | 当前使用示例 |
|---|---|---|---|
| 法杖 | 加速 | 倒计时速度×1.5；持续时间由卡牌指定；重复刷新，不叠加强度 | 疾行符：自身法杖加速3秒 |
| 法杖 | 减速 | 倒计时速度×0.7；持续时间由卡牌指定；重复刷新，不叠加强度 | 冰针：5直伤，敌方法杖减速2秒 |
| 法杖 | 充能 | 立即扣减当前剩余计时，最低0，溢出丢弃 | 充能符：自身法杖充能0.5秒；回响弹：命中敌人后自身法杖充能0.25秒 |
| 角色 | 灼烧 | 每秒按层数伤害，先扣盾，随后减1层；无视固定减伤，上限30 | 余烬弹：4直伤，附加4层 |
| 角色 | 中毒 | 每秒按层数直接扣生命，无视护盾与固定减伤；不自然衰减，上限30 | 毒刺：2直伤，附加2层 |
| 角色 | 感电 | 后续弹丸每次命中消耗1层，额外6直伤；持续伤害不触发，上限6 | 电弧：6直伤，附加2层 |
| 角色 | 护盾 | 优先吸收直伤和灼烧；不阻止状态附着，不阻挡中毒，上限55 | 护盾术：自身角色获得17点 |

法杖与角色是两个逻辑目标。当前每个角色只有一根法杖，内部仍保留单单位数据结构，但关键词声明 `target`，卡牌效果声明 `selfWand` / `enemyWand`。未来多法杖版本需要显式法杖ID与选取规则，不能直接假设当前数据结构已经支持多法杖。

### 加速与充能，不能混为一谈

- **加速：条走得更快**。剩余0.9秒、速度×1.5时，若期间无其他变化，约0.6秒后施放。
- **充能：条直接跳进**。剩余0.9秒时充能0.5秒，立刻剩余0.4秒；之后仍按当前速度走。
- 二者都操作现有的同一条施法计时，不新增魔力、充能槽或整轮重装。
- 加速与减速共存采用乘法：1.5×0.7=1.05。界面显示总计时倍率，避免玩家误以为抵消或相加。
- 界面剩余秒数是**法杖计时量**，不是考虑未来效果到期后的精确现实等待时间。

## 3. 卡牌不等于关键词

### 保留，但从关键词表移除

**引爆弹**：8基础直伤，命中时消耗敌方角色全部灼烧，每层追加2直伤。追加伤害可以被护盾和固定减伤抵挡。没有灼烧时仍有基础伤害。

**净化**：自身角色灼烧、中毒各减少3层，清空感电并回复4生命；另清除自身法杖减速。这是明确的跨目标卡牌效果，不表示「减速是角色状态」。加速不被清除。

### 新增的验证卡

1. **疾行符**：施放时 → 自身法杖 → 加速 → 3秒。
2. **充能符**：施放时 → 自身法杖 → 充能 → 0.5秒。
3. **回响弹**：5基础直伤；命中敌方角色时 → 自身法杖 → 充能 → 0.25秒。命中障碍不充能，敌人有护盾仍可触发。

这三张卡用于验证「同一机制，多种触发来源」。充能符和回响弹复用同一套充能处理，不各写一份规则。

原来的进阶修饰卡「高速」改名为**弹速强化**，仍只提高弹丸飞行速度，不改变法杖计时，避免与加速混淆。

## 4. 发动与边界规则

1. 每根法杖每个模拟步最多发动一个根组合，正常间隔仍由法杖决定。
2. 根组合发动时，**先建立下一发的完整计时，再执行本次卡牌效果**。所以充能符减少的是下一发的等待，不会被重置覆盖。
3. 充能把计时推进到0后，不在该效果调用中递归施法，最早下一模拟步发动。
4. 多次充能按顺序扣减。达到0后的额外充能不储存、不溢出到下下发。
5. 远端载荷中的自身辅助效果仍作用于施法者及其法杖，而非载荷碰撞位置所属敌人。
6. 固定步顺序仍为双方施法 → 弹丸命中及其效果 → 角色持续伤害 → 判定胜负。命中带来的减速/充能从后续施法检查起影响发动。
7. 灼烧/中毒首次施加1秒后开始结算，叠加不推迟下一跳；护盾不阻止效果附着。

## 5. 界面与试验路线

- 双方生命区下面分成「角色」「法杖」两行，避免把所有图标堆在角色身上。
- 加速/减速在法杖行显示剩余持续时间；充能是短暂的「刚刚 −0.50s」反馈，不伪装成可堆层状态。
- 法杖杖尖用颜色环表示加速/减速；施法条显示总计时倍率。
- 关键词面板分目标组。引爆弹、净化在卡库显示动作标签，不占关键词条目。
- 新预设「加速充能」：疾行符 → 回响弹 → 充能符 → 重矛。暂停并单步观察：疾行符后计时走快，充能符后下一发剩余量直接减少，回响弹命中时还能再次推进。

## 6. 设计取舍与尚未解决的问题

- **占用一次施法不是免费增益**：充能符本身仍要等到轮到它才发动。单杖里纯充能可能不如直接多打一发；本轮先验证语义与反馈，不声称它已具备足够强度。
- **回响弹给了充能一个更有意义的载体**：命中时间与当前队列相位影响充能收益。慢弹、障碍与溢出会改变收益，而非无条件加攻速。
- **双重充能存在高频循环风险**：两个充能符可把0.95秒下一发推至0；当前仅保证不在同一帧无限递归，仍可能每个模拟步施法。正式平衡前应比较最小施法间隔、同来源触发次数限制或不允许自充能等方案。本轮没有暗中添加第二套冷却来掩盖问题。
- 加速持续时间的刷新收益、速射杖对状态流的优势、进阶双重/强化强度仍待验证。功能测试通过不等于竞技平衡或真实玩家可读性通过。
- 暂不增加冻结、沉默等新控制关键词：先验证两类目标和三种计时操作是否足够清楚，再扩展；全自动战斗过量硬控可能让失败显得无从应对。

## 7. 验证结果

`node prototype/engine.test.cjs`：35组测试通过，覆盖168种预设×法杖×对手×障碍配置。新增分类校验、加速刷新/到期、加减速共存、充能跨循环、溢出、非递归、自身目标、障碍与重置回归。

Edge 浏览器验收：目标分组、加速倍率、充能反馈与日志、重置、390px无横向溢出；另重跑原有完整交互回归。截图与脚本保存在 `output/playwright/`。
